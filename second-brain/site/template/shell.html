Everything this project decided, in one place.

Genesis carries its thinking in four long documents — an architecture plan, a delivery roadmap, an engineering constitution, and a setup guide. Together they run to about 115,000 characters, and the reasoning you need is never in the one you opened.

This is a wiki compiled from those documents by Claude Code. Forty short pages, one idea each, cross-linked and cited back to the section they came from. The documents stay canonical; this is the readable index over them.

Sources are read where they live and never copied. /brain:ingest compiles them into pages.

Four things you do with it

Each one works here, and each has a command in Claude Code that does the same job with the files open.

The one rule that makes it trustworthy

You own the sources. Claude owns the wiki. Nothing Claude writes ever lands in your source documents, so its interpretation can never be mistaken for your record. You can recompile from clean sources at any time, roll back a bad run, or change models entirely without losing ground truth.

That is also why the four Genesis documents are referenced here rather than copied — a snapshot would be a second copy of the same facts, quietly drifting from the real file.

Employees

Everything that does work in this repository under its own name. Each one is read from the file that defines it — the same file Claude Code reads to run it — so a role here cannot drift from the role it actually has. The work is read from git history, the run ledger and the activity log, and what is running now from the agents themselves as they start and stop.

Dispatch a task

Hand work to the agents. A watcher on the agents' machine picks each task up within half a minute and starts a dispatcher for it, which gives it to the employee best placed to do it — or to the one you choose. Every task ends with a one-line outcome here, and the work shows on Employees while it runs.
